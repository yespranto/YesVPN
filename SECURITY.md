# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability (such as a DNS/IPv6/kill-switch leak, named-pipe privilege escalation, or credential exposure), please report it privately rather than opening a public issue:

- **Email:** [hello@yespranto.com](mailto:hello@yespranto.com)
- **Website:** [https://www.yespranto.com](https://www.yespranto.com)

Please include steps to reproduce, Windows version, and any relevant (masked) diagnostics output.
